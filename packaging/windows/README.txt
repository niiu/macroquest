МАКРОКВЕСТ 0.1.0 — Windows 10/11

Запуск: Macroquest.exe открывает редактор в браузере по умолчанию.
Node.js и доступ в интернет для работы не нужны.
Используется .NET Framework 4, входящий в поддерживаемые версии Windows.

Приложение обслуживает только локальный адрес http://127.0.0.1:4173/.
В области уведомлений Windows появляется значок: открыть редактор / остановить.
Закрытие вкладки браузера не останавливает локальный сервер.
Повторный запуск открывает существующий экземпляр.

ПРОЕКТЫ И СОХРАНЕНИЯ
Данные находятся в хранилище браузера, а не в папке программы.
Используйте тот же браузер и профиль, чтобы видеть прежние проекты.
Перед сменой браузера или очисткой его данных экспортируйте квест в JSON.
Удаление программы не удаляет данные из браузера.
Готовые квесты можно экспортировать в автономный HTML.

PORTABLE
Распакуйте ZIP в любую папку и запустите Macroquest.exe.
Перенос папки не переносит проекты: используйте экспорт/импорт JSON.

УСТАНОВКА
Установщик устанавливает программу для текущего пользователя без прав администратора.
Удаление доступно в параметрах Windows: Установленные приложения — Макроквест.
Перед обновлением/удалением завершите сервер через значок в области уведомлений.

Эта сборка не подписана сертификатом издателя.
Исходный код: https://github.com/niiu/macroquest
