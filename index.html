ПУТЬ МЕЖДУ СЦЕНАМИ

Новый переход

Условия доступа

Без условий путь доступен всегда. Предметы проверяются по количеству, флаги — по состоянию.

Один бросок при выборе пути. Пустой диапазон означает провал и переход в сцену провала. Последствия ниже применяются только при успехе.

При переходе

Выполняются сверху вниз после проверки условий. Изменить на −1 — забрать один предмет; +1 — выдать. Если предметов не хватает, переход недоступен и ничего не изменяется. При повторном переходе последствия выполняются снова.
